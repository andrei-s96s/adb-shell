# Changelog

Все заметные изменения проекта документируются в этом файле. Формат
основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/) —
секции сгруппированы по смыслу для пользователя (что добавлено/исправлено/
изменено), а не по коммитам. Заметки к GitHub-релизу собираются из секции
соответствующей версии этого файла (см. `scripts/changelog-extract.js` и
`.github/workflows/release.yml`) — перед тегом релиза `[Unreleased]`
переносится в новую версионную секцию с датой.

## [Unreleased]

### Added

- Запуск макроса сразу на всех подключённых и готовых устройствах —
  переменные `${ИМЯ}` спрашиваются один раз на весь батч
- Журнал запусков макросов (кто/когда/на каком устройстве, результат по
  каждому шагу) — персистентный, переживает перезапуск приложения
- Активный тег-фильтр списка устройств теперь сужает и все операции «на
  все устройства» (broadcast, зеркалирование, скриншот со всех, установка
  APK на все, запуск макроса на всех), а не только видимый список в
  сайдбаре
- Полный диагностический архив устройства в один клик (`adb bugreport`)
  во вкладке «Мониторинг» — логи, dumpsys, состояние системы целиком;
  можно прервать, если сбор надолго затянулся
- Периодический запуск макроса (каждые N минут, на всех подключённых и
  готовых устройствах) — независимо от того, открыта ли вкладка
  «Макросы»; как и у хоткея, недоступно макросам с переменными `${ИМЯ}`
- Проверка подписи APK в Библиотеке: sha256 всего файла всегда, плюс
  best-effort извлечение сертификата JAR/v1-подписи (издатель, срок
  действия, отпечаток), если файл его содержит

## [1.6.0] - 2026-09-07

Большой релиз: массовые действия и оптимизации для приложений и APK,
управление порядком выполнения в макросах (задержки, условные шаги,
глобальный хоткей, теги), устройства стали заметно удобнее (теги,
история подключений, автопереподключение, честная индикация проблемных
состояний), `adb` теперь вшит в сборку на всех трёх платформах, а не
только на Windows, и релиз для macOS больше не тащит вдвое лишнего веса.
Плюс список исправленных багов и закрытых security-проблем, накопленных
за ревью всего проекта.

### Added

- Пакетные действия сразу для нескольких выбранных приложений: force-stop,
  очистка данных, включить/выключить
- Быстрый фильтр приложений с доступным обновлением на F-Droid
- Автоматическая очистка старых снапшотов устройства (не больше 5 на
  устройство) и сравнение двух снапшотов между собой
- Обнаружение устаревших дублирующихся версий APK внутри библиотеки
- Скриншот сразу со всех подключённых устройств
- Экспорт текущего отфильтрованного вида Logcat в текстовый файл
- Автодополнение поля ввода shell-команды по сохранённой истории
- Отмена зависшей shell-команды прямо из интерфейса
- Результат каждого шага макроса виден живьём по мере выполнения, а не
  только по завершении всего макроса
- Запуск макроса по глобальной горячей клавише (работает даже когда окно
  не в фокусе)
- Теги и чипы-фильтр для макросов — тот же принцип, что и в Библиотеке APK
- Задержки и условные шаги (flow control) в редакторе макроса
- `adb` вшит в сборку не только для Windows, но и для macOS и Linux —
  Android Platform Tools отдельно ставить не нужно ни на одной платформе
- Релиз для macOS разделён на отдельные архивы под Intel и Apple Silicon —
  вдвое меньше скачивать, чем один universal-архив
- Заметная индикация проблемных состояний устройства (offline/не
  авторизовано/нет прав доступа) — цветная рамка и значок с подсказкой
  вместо голого технического статуса
- Теги устройств по serial — тот же принцип, что и у макросов/Библиотеки APK
- Автопереподключение сетевых профилей при обрыве связи в процессе работы,
  не только при старте приложения
- История подключений: все когда-либо увиденные устройства, автодополнение
  поля host, повторное подключение в один клик
- Сравнение устройств дополнено сводкой по getprop (модель, версия
  Android, SDK, патч безопасности) — расходящиеся значения подсвечены
- Сочетание клавиш для глобального хоткея скриншота теперь можно
  настроить, а не только включить/выключить — с бейджем, честно
  показывающим, реально ли оно сейчас активно

### Fixed

- Результат пакетного удаления приложений отражает, сколько реально
  удалилось, а не сколько было запрошено
- Карточка приложения больше не может показать данные не того пакета при
  быстром переключении между строками списка
- Разбор шагов макроса и сырого shell-ввода учитывает кавычки — аргумент с
  пробелом внутри кавычек больше не рвётся на части
- Вывод adb-процессов декодируется потоково (StringDecoder) — многобайтовые
  UTF-8-символы (кириллица и т.п.) на границе чанков больше не превращаются
  в мусор
- Скриншот устройства получил ту же защиту от зависания по таймауту, что и
  обычные команды
- Самопроизвольное завершение `adb logcat` теперь замечается и показывается
  в интерфейсе, а не тихо зависает без вывода
- Кнопка «Восстановить» снапшота блокируется на время восстановления
- Распознаётся статус устройства «no permissions» (два слова через
  пробел) — раньше ошибочно уходил в «unknown»
- Список устройств в сайдбаре мог схлопнуться почти до нуля по высоте,
  если остальные секции (профили подключения, сопряжение по коду) не
  помещались — теперь не ужимается ниже разумного минимума, а редко
  нужные секции свёрнуты по умолчанию

### Security

- Удаление файла отклоняется, если путь целится за пределы собственной
  директории
- `packageName` percent-encode’ится при обращении к API F-Droid
- Накопленный stdout/stderr процесса `adb` ограничен по объёму — защита от
  исчерпания памяти на аномально болтливой команде
- Скачанное обновление сверяется с опубликованной sha256-контрольной
  суммой перед запуском

### Changed

- Logcat: входящие строки объединяются в одно обновление списка за кадр
  вместо одного обновления на строку
- Установка на все устройства и экспорт наборов приложений выполняются с
  ограниченной параллельностью, а не строго по одному
- Мониторинг: 4 отдельных вызова `adb` за тик опроса объединены в один
  shell-вызов
- Мониторинг и Logcat приостанавливают фоновую работу, пока их вкладка не
  активна
- Приложения: иконки кешируются, поиск с debounce, список не
  перестраивается заново при каждом выборе строки
- Библиотека APK сканируется асинхронно, результат разбора `aapt2`
  кешируется
- Карточка «Безопасность» переиспользует уже выполненный getprop-дамп
  вместо 4 отдельных вызовов
- CI: `npm ci` + кеш `node_modules` и вендорных бинарников между запусками

## [1.0.0] - 2026-09-04

Первый релиз единого Electron-клиента для macOS/Windows/Linux — объединяет
более раннее Swift/macOS-only приложение и отдельный Electron-порт в один
кроссплатформенный продукт.

### Added

- Устройства: USB и сеть, никнеймы, профили подключения, закреплённые
  вкладки, mDNS-автообнаружение
- Приложения: список, детали, установка/удаление, разрешения, экспорт APK
- Файловый браузер устройства
- Shell-раннер с историей и избранным, broadcast-режим
- Мониторинг: CPU/RAM/батарея, процессы, сетевая статистика,
  ANR/tombstones, экранное время приложений
- Макросы: переменные, автозапуск при подключении, импорт/экспорт
- Библиотека APK: локальный каталог, теги, проверка обновлений с F-Droid
- Зеркалирование экрана через `scrcpy`
- Снапшоты устройства, сравнение устройств по установленным пакетам
- Наборы приложений (экспорт/импорт) с разрешениями
- Быстрый поиск ⌘K/Ctrl+K
- Упаковка electron-builder: NSIS для Windows, zip для macOS
