# Roadmap

План развития ADB Shell по версиям. Каждая версия — отдельный тег и релиз на
GitHub (см. [release.yml](.github/workflows/release.yml)).

## v1.0.0 — MVP ✅ выпущено

- Устройства: USB + сетевой adb, автоопределение, подключение по IP
- Приложения: список, поиск, установка/удаление APK, force-stop, очистка
  данных, включение/отключение
- Разрешения: просмотр и выдача/отзыв runtime-permissions
- Библиотека APK с настраиваемой папкой, drag&drop
- Shell-раннер и скриншот экрана
- Премиальный тёмный UI, кастомная иконка
- Автообновление через GitHub Releases
- Юнит-тесты на парсинг (`dumpsys`, `devices -l`, `pm list packages`), CI на
  каждый push, release-workflow на тег

## v1.1.0 — Диагностика ✅ выпущено

- Live Logcat: стриминг `adb logcat -v threadtime`, фильтр по тексту/уровню,
  подсветка ошибок, автоскролл
- Экспорт списка установленных пакетов в CSV
- Персистентная история shell-команд (UserDefaults) + избранные команды
  быстрого запуска
- Индикатор версии/сборки Android (`ro.build.version.release`/`sdk`) в шапке
- `adb` вшит прямо в `.app` — релиз не требует отдельной установки Platform
  Tools на машине пользователя

## v1.2.0 — Работа с файлами ✅ выпущено

- Файловый браузер устройства (вкладка «Файлы»): навигация с хлебными
  крошками, push (drag&drop и кнопка) и pull, создание папок, удаление
- Экспорт APK установленного приложения обратно на Mac (`pm path` + pull) —
  кнопка «Экспортировать APK» в деталях приложения
- Пакетная установка нескольких APK с отчётом по каждому файлу
- Пакетное удаление приложений (режим мультивыбора в списке)

## v1.3.0 — Множественные устройства и профили ✅ выпущено

- Закреплённые вкладки устройств (иконка pin в списке) — полоска для
  быстрого переключения между несколькими подключёнными устройствами
- Профили подключения: сохранённые IP/порты с именами, автоподключение при
  запуске (звезда у профиля)
- Сопряжение по коду для Android 11+ wireless debugging (`adb pair`) —
  без реального сканирования QR (adb CLI его не отдаёт), но по тому же коду,
  что показывает экран «Сопряжение устройства по коду»
- Быстрые действия в Shell: reboot recovery/bootloader, `adb root`/`remount`
  для userdebug/eng-сборок

## v1.4 — Полировка и надёжность

- Полноценная нотаризация сборки (Apple Developer ID) — уберёт
  предупреждения Gatekeeper при первом запуске
- UI-тесты на ключевые сценарии (установка APK, выдача разрешения)
- Локализация интерфейса (en/ru переключаемо)
- Настройки приложения: тема, поведение автообновления, дефолтные пути

Приоритеты и порядок могут смещаться по мере использования — фидбек и баг-репорты
из реальной работы с устройствами важнее плана.
