# Roadmap

План развития ADB Shell по версиям. Каждая версия — отдельный тег и релиз на
GitHub (см. [release.yml](.github/workflows/release.yml)).

## v1.0.0 — MVP ✅ выпущено

- Устройства: USB + сетевой adb, автоопределение, подключение по IP
- Приложения: список, поиск, установка/удаление APK, force-stop, очистка
  данных, включение/отключение
- Разрешения: просмотр и выдача/отзыв runtime-permissions
- Библиотека APK с настраиваемой папкой, drag&drop
- Shell-раннер и скриншот экрана
- Премиальный тёмный UI, кастомная иконка
- Автообновление через GitHub Releases
- Юнит-тесты на парсинг (`dumpsys`, `devices -l`, `pm list packages`), CI на
  каждый push, release-workflow на тег

## v1.1.0 — Диагностика ✅ выпущено

- Live Logcat: стриминг `adb logcat -v threadtime`, фильтр по тексту/уровню,
  подсветка ошибок, автоскролл
- Экспорт списка установленных пакетов в CSV
- Персистентная история shell-команд (UserDefaults) + избранные команды
  быстрого запуска
- Индикатор версии/сборки Android (`ro.build.version.release`/`sdk`) в шапке
- `adb` вшит прямо в `.app` — релиз не требует отдельной установки Platform
  Tools на машине пользователя

## v1.2.0 — Работа с файлами ✅ выпущено

- Файловый браузер устройства (вкладка «Файлы»): навигация с хлебными
  крошками, push (drag&drop и кнопка) и pull, создание папок, удаление
- Экспорт APK установленного приложения обратно на Mac (`pm path` + pull) —
  кнопка «Экспортировать APK» в деталях приложения
- Пакетная установка нескольких APK с отчётом по каждому файлу
- Пакетное удаление приложений (режим мультивыбора в списке)

## v1.3.0 — Множественные устройства и профили ✅ выпущено

- Закреплённые вкладки устройств (иконка pin в списке) — полоска для
  быстрого переключения между несколькими подключёнными устройствами
- Профили подключения: сохранённые IP/порты с именами, автоподключение при
  запуске (звезда у профиля)
- Сопряжение по коду для Android 11+ wireless debugging (`adb pair`) —
  без реального сканирования QR (adb CLI его не отдаёт), но по тому же коду,
  что показывает экран «Сопряжение устройства по коду»
- Быстрые действия в Shell: reboot recovery/bootloader, `adb root`/`remount`
  для userdebug/eng-сборок

## v1.4.0 — Настройки и качество ✅ выпущено

- Экран настроек (шестерёнка в сайдбаре): вкл/выкл автопроверку обновлений,
  системные приложения по умолчанию, быстрая очистка истории shell/профилей,
  ссылки на репозиторий и Releases
- 48 юнит-тестов (было 30): добавлены проверки для парсера файлов
  устройства, профилей подключения, фильтрации списка приложений
- `ConnectionProfileStore` переведён на инъекцию `UserDefaults` для тестов

**Скорректировано по ходу дела** (два пункта из исходного плана не вошли —
честно, а не тихо):
- *Нотаризация (Apple Developer ID)* — требует платного аккаунта разработчика
  и учётных данных, принадлежащих вам; агент физически не может завести или
  использовать чужой Apple ID/оплату. Если хотите убрать предупреждение
  Gatekeeper — заведите Developer ID сертификат и попросите добавить шаг
  `codesign`/`notarytool` в `release.yml`, это можно сделать в любой момент.
- *Полная локализация en/ru* — оставлена вне плана: инструмент личный,
  интерфейс на русском, овчинка выделки не стоит. Если понадобится
  конкретному кругу пользователей — можно вернуть в план отдельной задачей.
- *UI-тесты* — заменены на расширенный набор юнит-тестов бизнес-логики:
  полноценные XCUITest требуют Xcode (на этой машине только Command Line
  Tools), а юнит-тесты дешевле и покрывают то же самое, что реально ломается
  (парсеры, фильтры, хранилища).

## v1.5.0 — Наборы приложений и локализация ✅ выпущено

- **Наборы приложений**: выгрузка нескольких приложений вместе с их выданными
  runtime-разрешениями в один `.zip` (кнопка «Экспортировать выбранные» в
  режиме мультивыбора), и установка такого набора на другое устройство одним
  кликом («Импорт набора…») — APK ставятся и сразу получают те же разрешения
  без ручной настройки на новом устройстве
- **Полная локализация интерфейса**: русский и английский, переключатель в
  Настройках (Системный / Русский / English), применяется мгновенно без
  перезапуска. Ранее в v1.4.0 этот пункт был сознательно исключён из плана
  как «не стоит усилий для личного инструмента» — пользователь явно попросил
  вернуть его, и это было сделано полностью, а не для галочки: 166
  локализованных строк, все View/ViewModel/Service
- 50 юнит-тестов (было 48): добавлен round-trip тест для формата наборов
  приложений
